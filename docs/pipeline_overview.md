# Pipeline Overview — Proteomics Analysis of 3xTg-AD

## Background

The **3xTg-AD** mouse carries three familial Alzheimer's disease mutations (*APP Swedish*, *MAPT P301L*, *PSEN1 M146V*) and is a widely used model for studying amyloid and tau pathology simultaneously.

This pipeline processes label-free quantification (LFQ) proteomics data generated by Proteome Discoverer from cortical/hippocampal tissue of 3xTg-AD and wild-type (WT) mice of both sexes.

---

## Step 1 — Preprocessing (`01_preprocessing.R`)

### 1.1 Data loading and gene symbol curation
Raw exported abundances from Proteome Discoverer are loaded. A small set of proteins lacked annotated gene symbols in the database; these are filled manually from a curated dictionary.

### 1.2 Abundance column extraction
Columns matching `"Abundance: "` are extracted and renamed to a consistent `"mouseXX"` format.

### 1.3 Missing value QC
A bar chart of NAs per sample is generated to flag potential technical failures.

### 1.4 Preliminary PCA
A PCA using only complete-case proteins (no imputation) is plotted to inspect overall sample structure and batch effects before imputation.

### 1.5 Group separation
Samples are split into four subgroups: WT female, WT male, 3xTg female, 3xTg male. This ensures that outlier removal and imputation respect biological grouping.

### 1.6 Outlier removal
For each protein within each group, values beyond ±3×IQR from the group quartiles are set to NA. This conservative threshold avoids removing true biological signal while eliminating technical extremes.

### 1.7 Coverage filter
Proteins with fewer than **3 valid (non-NA) values** in any group are discarded. Only proteins detected in **all four groups** are retained for downstream analysis.

### 1.8 Median imputation
Remaining NAs within each group are replaced by the **within-group median** of that protein. This approach preserves the group mean and is appropriate when missingness is not purely at random (MNAR) but moderate.

### 1.9 Normalization
A per-sample correction factor is computed:

```
factor_i = mean_abundance_i / min(mean_abundances)
```

Each sample's values are divided by its factor, bringing all samples to a common scale without log-transforming the data at this stage.

---

## Step 2 — Differential Expression (`02_differential_expression.R`)

### 2.1 Group means
Mean abundance per protein is computed for WT and 3xTg groups separately.

### 2.2 Normality testing
Shapiro-Wilk test is applied to each group vector per protein. Constant vectors (no variance) automatically receive p = 1 (treated as normal) to avoid errors.

### 2.3 Statistical test selection
| Condition | Test |
|-----------|------|
| Both groups normal (SW p > 0.05) | Welch's t-test |
| At least one group non-normal | Wilcoxon rank-sum test |
| Identical values in both groups | p = 1 (no difference) |

### 2.4 Fold change
Log₂ fold change is calculated as:

```
log2FC = log2(mean_3xTg / mean_WT)
```

### 2.5 Significance thresholds
| Parameter | Value |
|-----------|-------|
| p-value cutoff | 0.05 |
| FC threshold (±) | 25% change from baseline |
| LFCP (upper) | log₂(1.25) ≈ 0.322 |
| LFCN (lower) | log₂(0.75) ≈ −0.415 |

Proteins passing both thresholds are classified as **up-regulated** or **down-regulated**.

---

## Step 3 — Visualization (`03_visualization.R`)

### 3.1 PCA
Samples are projected onto the first two principal components after scaling. Points are colored by genotype and shaped by sex, with sample labels.

### 3.2 Volcano plot
Classic volcano layout (log₂FC on x-axis, −log₁₀ p-value on y-axis). Up-regulated proteins are shown in red, down-regulated in blue, unchanged in grey. Top candidates by significance and extreme fold change are labeled with `ggrepel`.

### 3.3 Heatmap
Log₁₀-transformed abundances of all significant proteins are displayed as a clustered heatmap (Euclidean distance, complete linkage). Columns are annotated by genotype. Isoforms are distinguished by appending `_isoN` to the gene name.

### 3.4 Enrichment plots (GO & KEGG)
Top 20 terms per category (GO Biological Process, Molecular Function, Cellular Component; KEGG pathways) are shown as horizontal bar charts colored by FDR value. Enrichment results were obtained externally from **STRING** and are read from Excel files.

### 3.5 Interaction network
A protein–protein interaction graph is built with `igraph` using STRING-exported edges. Node size encodes −log₁₀(p-value); node fill encodes log₂FC (blue→white→red); node shape distinguishes up- vs down-regulated proteins. Layout uses the Fruchterman–Reingold algorithm (`niter = 10000`).
