# data

Intermediate files generated by the pipeline and required for downstream steps.

| File | Generated by | Description |
|------|-------------|-------------|
| `ajustado.xlsx` | `01_preprocessing.R` | Normalized abundance matrix |
| `entera_3xtg.xlsx` | `01_preprocessing.R` | Full protein table (filtered proteins only) |
| `Enrichment_Results_3xtg_005.xlsx` | External (STRING) | GO/KEGG enrichment results |
| `RED_3xtg_005.xlsx` | External (STRING) | Protein–protein interaction edges |

Files generated by the scripts are not tracked by git.
External files (STRING outputs) should be placed here manually.
